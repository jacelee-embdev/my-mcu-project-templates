# ESP32-S3

## Overview

A basic ESP32-S3 project template using ESP-IDF and CMake. The application entry point is in `main/main.c`. The current `app_main()` is empty and ready for application code.

## Layout

- `CMakeLists.txt`: project build configuration
- `sdkconfig`: ESP-IDF project configuration
- `partitions-16MiB.csv`: custom partition table
- `main`: application component and entry point
