# ESP32-S3

## 简介

基于 ESP-IDF 和 CMake 的 ESP32-S3 基础工程模板。应用入口位于 `main/main.c`，当前 `app_main()` 为空，可在此添加业务代码。

## 目录

- `CMakeLists.txt`：工程构建配置
- `sdkconfig`：ESP-IDF 工程配置
- `partitions-16MiB.csv`：自定义分区表
- `main`：应用组件与入口代码
