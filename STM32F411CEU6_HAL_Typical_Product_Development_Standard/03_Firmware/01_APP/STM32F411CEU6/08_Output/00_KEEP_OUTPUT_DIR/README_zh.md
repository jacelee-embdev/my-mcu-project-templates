# 08_Output 目录占位说明

本目录用于保证 `08_Output` 能够被 Git 跟踪，并在克隆或检出工程时自动创建。

- `08_Output` 中的其他文件通常由 Keil 编译生成，并由仓库根目录的 `.gitignore` 规则过滤。
- 请勿删除 `00_KEEP_OUTPUT_DIR` 及本说明文件。
- 清理编译产物时，请保留本目录。
